# Spectrum Analyser

Android app that shows a live spectrum of whatever the phone is playing (Spotify, YouTube, etc.).

- Display modes: Bars, Line, Waterfall
- Colours: 6 preset palettes plus a custom start/end gradient
- Falls back to the microphone on phones that block system-audio capture

Every push to `main` builds the APK with GitHub Actions and attaches it to a new release.
